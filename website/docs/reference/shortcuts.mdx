---
title: Keyboard shortcuts
description: Every keyboard shortcut of GEDRoots, on macOS and on Windows and Linux.
---

Every command is also in the menu bar and in the command palette. Commands without a shortcut are listed in [All commands](/reference/commands).

## Files

| Command | macOS | Windows and Linux |
| --- | --- | --- |
| New File | <kbd>⌘N</kbd> | <kbd>Ctrl+N</kbd> |
| Open… | <kbd>⌘O</kbd> | <kbd>Ctrl+O</kbd> |
| Save | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |
| Save As… | <kbd>⌘⇧S</kbd> | <kbd>Ctrl+Shift+S</kbd> |
| File Settings… | <kbd>⌘,</kbd> | <kbd>Ctrl+,</kbd> |
| Quit | <kbd>⌘Q</kbd> | <kbd>Ctrl+Q</kbd> |

## Editing

| Command | macOS | Windows | Linux |
| --- | --- | --- | --- |
| Undo | <kbd>⌘Z</kbd> | <kbd>Ctrl+Z</kbd> | <kbd>Ctrl+Z</kbd> |
| Redo | <kbd>⌘⇧Z</kbd> | <kbd>Ctrl+Y</kbd> | <kbd>Ctrl+Shift+Z</kbd> |
| Find (focus the search field) | <kbd>⌘F</kbd> | <kbd>Ctrl+F</kbd> | <kbd>Ctrl+F</kbd> |
| Media… | <kbd>⌘⇧M</kbd> | <kbd>Ctrl+Shift+M</kbd> | <kbd>Ctrl+Shift+M</kbd> |
| Show suggestions (raw GEDCOM editor) | <kbd>Ctrl+Space</kbd> | <kbd>Ctrl+Space</kbd> | <kbd>Ctrl+Space</kbd> |

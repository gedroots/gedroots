title: Share your tree

Your `.ged` file is already a standard file: anyone with GEDCOM 7 software can open it. The **File › Export** menu covers the other cases.

:::warning[Living people]
Exports contain everyone in your tree, including living people. Before you share or publish, check that the people concerned agree, or remove them from the copy you send.
:::

## Send the complete tree with its media

To give your tree to a relative, or to move it to another computer with every scan and photo:

1. Select **File › Export › GEDZIP with Media…**.
2. Choose where to save the `.gdz` file.

A GEDZIP archive is the GEDCOM 7 standard for a tree and its media in one file. It contains `gedcom.ged` and the media files:

- files inside your `.ged` folder keep their subfolder, such as `Records/…`;
- files elsewhere on your disk go into a `media/` folder;
- the paths in the archive's GEDCOM are rewritten to match.

Your own `.ged` file and media are not modified. In GEDRoots, the recipient opens the archive with **File › Import GEDCOM…**. If some media files can't be found, GEDRoots lists them at the end of the export, each with a link to its media, so you can fix them and export again.

## Give a file to older software

Many programs don't read GEDCOM 7 yet. For them, select **File › Export › GEDCOM 5.5.1…**.

GEDRoots converts what GEDCOM 5.5.1 expresses differently: shared notes, French Republican dates, roles, file formats, line lengths. Structures that only exist in GEDCOM 7, and GEDRoots' own settings, are left out. Use this file to share, not to work on: your GEDCOM 7 file remains the reference.

## Publish on Geneanet

[Geneanet](https://www.geneanet.org) imports GEDCOM 5.5.1, with a few habits of its own. GEDRoots prepares the file for it:

1. Select **File › Export › GEDCOM for Geneanet…** and save the file.
2. GEDRoots opens Geneanet's import page in your browser.
3. Sign in to Geneanet and upload the file there.

Compared with the plain GEDCOM 5.5.1 export, places and witness roles are written the way Geneanet expects. For example, when the first jurisdiction of your place format is a locality, `Le Moulin, Agneaux, …` becomes `[Le Moulin] - Agneaux, …`.

Geneanet offers no way for other software to upload a tree, so the upload stays manual.

## Save a copy

**File › Save As…** (<kbd>⌘⇧S</kbd> / <kbd>Ctrl+Shift+S</kbd>) saves the tree under another name. GEDRoots then works on the new file.

# Country packs

What genealogy records each country kept, and from when to when, so that GEDRoots can say where
to look for a birth, a marriage or a death (`crates/gedcom/src/countries.rs`). One file per country,
named by its ISO 3166-1 code; `generic.yml` is used for the other countries and for periods that a
pack does not cover. The format is documented in [docs/country-packs.md](../../../docs/country-packs.md).

The data in this folder is dedicated to the public domain (CC0 1.0), so that other genealogy
software can reuse it. Corrections and new countries are welcome: cite your source in the pull
request.
